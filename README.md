# 📚 Flashcard Learning App

## 📌 Project Overview
The Flashcard Learning App is a simple and interactive web application built using HTML, CSS, and JavaScript. It helps users learn and revise concepts using question-and-answer flashcards.

Users can click on a card to reveal the answer and navigate between cards using Previous and Next buttons.

## 🎯 Objectives
- Create at least 10 question-and-answer flashcards.
- Add a 3D flip animation.
- Implement Previous and Next navigation.
- Display a progress indicator.
- Practice HTML, CSS, and JavaScript.

## 🛠️ Technologies Used
- **HTML5** — Structure of the application.
- **CSS3** — Styling, layout, and flip animation.
- **JavaScript** — Card navigation, click events, and progress tracking.

## ✨ Features
- 10 predefined flashcards.
- Click-to-flip animation.
- Previous and Next buttons.
- Progress bar and percentage indicator.
- Responsive design for mobile and desktop.
- Simple and beginner-friendly interface.

## 🚀 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure all three files are in the same folder.
4. Open `index.html` in your browser, or use the Live Server extension.
5. Click on a flashcard to reveal its answer.
6. Use Previous and Next to navigate through the cards.
